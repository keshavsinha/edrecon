WHICH FILE DO I EDIT?
=====================
Change an explanation .............. knowledge/*.yaml
Add a new finding type ............. knowledge/*.yaml
Add authorised targets ............. your own scope.yaml (copy the example)
Add a new scanner .................. modules/<passive|system|web>/
Change console appearance .......... core/output.py
Change the banner .................. core/banner.py
